# Subspace

> Subspace was a real-time network-as-a-service platform — a dedicated global network built for latency-sensitive applications (WebRTC, VoIP/SIP, video conferencing, multiplayer gaming, fintech). Its Product API provisions PacketAccelerator, SIPTeleport, and WebRTC-CDN services. Authentication is OAuth2 client-credentials issuing 24-hour JWT bearer tokens via Auth0.

Note: The marketing site (www.subspace.com) remains reachable, but the API, identity, and status hosts (api./id./status.subspace.com) no longer resolve — the service has wound down operationally. Specs and SDKs below are preserved from the public subspace-com GitHub organization.
